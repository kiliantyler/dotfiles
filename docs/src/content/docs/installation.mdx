<Aside type="danger" title="These are one person's dotfiles">
Installing them replaces your shell, git, and SSH configuration with mine. Read the [managed files](/managed-dotfiles) first. Nothing here is supported.
</Aside>

## One command

```sh
curl -fsSL https://install.dotfiles.wiki/ | sh
```

Only macOS is supported for this repository. The command works on Linux for other repositories; see [your own repository](#your-own-repository).

## What happens

<Steps>
1. The [Cloudflare Worker](/management-tools/cloudflare) returns a shell script for the detected OS.

2. The script installs the Xcode Command Line Tools if `git` is missing, then installs chezmoi into `~/.local/bin`.

3. `chezmoi init --apply` clones the repository and renders every file into `~`.

4. The age key is decrypted. This is the only prompt: the passphrase for `key.txt.age`.

5. Homebrew is installed if missing, then `brew bundle` installs everything in the [Brewfile](/management-tools/homebrew). This is the slow step.

6. Homebrew bash becomes the login shell. `sudo` asks for your password once to register it in `/etc/shells`.
</Steps>

After it finishes, open a new terminal or start an agent. mise installs its tools on first use of each shim.

## After installation

Create `~/.config/secrets.env` with any API keys agents need, one `export NAME=value` per line, and `chmod 600` it. The shell sources it on every start. It is never tracked.

Register `~/.ssh/id_ed25519.pub` on GitHub as both an authentication and a signing key if the machine is new:

```sh
gh auth login
gh ssh-key add ~/.ssh/id_ed25519.pub --type authentication --title "$(hostname -s)"
gh ssh-key add ~/.ssh/id_ed25519.pub --type signing --title "$(hostname -s) signing"
```

## Your own repository

The installer is generic. Query parameters pick the repository:

| Parameter  | Default       | Values                                                   |
| ---------- | ------------- | -------------------------------------------------------- |
| `username` | `kiliantyler` | any account name                                         |
| `provider` | `github`      | `github`, `gitlab`, `bitbucket`, or a bare domain        |
| `repo`     | `dotfiles`    | repository name                                          |
| `branch`   | `main`        | branch name                                              |
| `os`       | user agent    | `macos`, `linux`, or `windows` for a PowerShell script   |

```sh
curl -fsSL 'https://install.dotfiles.wiki/?username=you&provider=gitlab&branch=dev' | sh
```

```powershell
iex "&{$(irm 'https://install.dotfiles.wiki/?username=you&os=windows')}"
```

The script runs `chezmoi init --apply <repo-url> --branch <branch>`, so the target repository has to be a chezmoi source directory.
