### Why bash and not zsh or fish?

Agents spawn shells constantly and assume POSIX syntax. fish broke `( … ) && …` one-liners, and zsh's glob expansion turned URLs with `?` into "no matches found" errors. Homebrew bash 5 runs everything agents write, and macOS's own bash 3.2 is too old to be worth configuring.

### Why is there no prompt, completion, or history tool?

Nobody looks at the prompt. Starship, atuin, zoxide, fzf, and eza were removed in October 2026 after shell and agent history showed no direct use for months.

### Why not 1Password for SSH and signing?

Every ssh connection, every signed commit, and every chezmoi template that read a secret produced an approval dialog. Unattended agents cannot click it. Keys now live in `~/.ssh`, Apple's agent holds them, and the only host that still goes through 1Password is one router whose key was never exported. See [Git and SSH](/managed-dotfiles/git-and-ssh).

### Where do secrets live?

In `~/.config/secrets.env`, mode 600, untracked. `~/.bashrc` sources it. The age-encrypted files in the repo hold only the sops key and the chezmoi key itself.

### How do I add a tool?

CLI tool: add a line to `~/.config/mise/config.toml`, run `mise install`, then `chezmoi re-add ~/.config/mise/config.toml`. App or library: add a line to the [Brewfile](/management-tools/homebrew) and run `chezmoi apply`.

### How do I remove one?

Delete the line, then uninstall by hand (`brew uninstall`, `mise uninstall`). The bootstrap scripts only install.

### Can I use the installer for my repository?

Yes. See [your own repository](/installation#your-own-repository). It works for any chezmoi source repository on GitHub, GitLab, Bitbucket, or a self-hosted domain.
