[chezmoi](https://www.chezmoi.io/) copies the `dotfiles/` directory of the repository into `~`, renaming files by convention and rendering the few that are templates.

## Where things are

| Path                           | Purpose                                                      |
| ------------------------------ | ------------------------------------------------------------ |
| `~/.local/share/chezmoi`       | the git clone; `.chezmoiroot` points chezmoi at `dotfiles/`  |
| `~/.config/chezmoi/chezmoi.yaml` | rendered from `.chezmoi.yaml.tmpl`; age settings and editor |
| `~/.config/chezmoi/key.txt`    | the age identity, decrypted once per machine                 |

## Naming

| Prefix or suffix | Effect                                   |
| ---------------- | ---------------------------------------- |
| `dot_`           | leading dot in the target name           |
| `private_`       | mode 600 for files, 700 for directories  |
| `executable_`    | mode +x                                  |
| `empty_`         | create the file even when it is empty    |
| `.tmpl`          | render as a Go template before writing   |
| `.age`           | decrypt with the age identity            |

## Templates

Only four files are templates, and each uses one value: `.chezmoi.homeDir`. There is no OS, hostname, or work branching. The config template itself is fifteen lines.

```yaml
encryption: age
age:
  identity: ~/.config/chezmoi/key.txt
  recipient: "age1…"
  suffix: .age
diff:
  exclude: [scripts]
edit:
  command: code
  args: ["--wait"]
```

Template functions that call a password manager (`onepasswordRead` and friends) are banned. They run on every `chezmoi status` and `chezmoi diff`, which turns a read-only command into an approval prompt.

## Scripts

| Script                                  | When                                      | Does                                                  |
| --------------------------------------- | ----------------------------------------- | ----------------------------------------------------- |
| `run_once_before_decrypt-age-key`       | first apply on a machine                  | decrypts `key.txt.age` with a passphrase prompt       |
| `run_onchange_after_brew-bundle`        | whenever the Brewfile's hash changes      | installs Homebrew if needed, then `brew bundle install` |
| `run_once_after_set-login-shell`        | first apply, after bash exists            | adds Homebrew bash to `/etc/shells`, `chsh`, `launchctl setenv SHELL` |

## Removed targets

`.chezmoiremove` lists paths that older versions of the repo managed. chezmoi deletes them on apply, which is how the fish, zsh, starship, and Karabiner configs left every machine.

## Day to day

```sh
chezmoi status          # what differs between repo and ~
chezmoi diff            # the actual diff
chezmoi apply           # write ~ from the repo
chezmoi re-add <file>   # pull a changed ~ file back into the repo
chezmoi cd              # shell in the clone to commit
```

Agents commit the clone directly. Nothing auto-commits or auto-pushes.
