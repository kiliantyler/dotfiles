Four tools do all the work. Each owns one layer and nothing overlaps.

| Tool                                   | Owns                                              | Source of truth                                   |
| -------------------------------------- | ------------------------------------------------- | ------------------------------------------------- |
| [chezmoi](/management-tools/chezmoi)   | every file under `~`, the bootstrap scripts       | `dotfiles/`                                       |
| [Homebrew](/management-tools/homebrew) | system packages, libraries, GUI apps, fonts       | `~/.config/homebrew/Brewfile`                     |
| [mise](/management-tools/mise)         | CLI tools and language runtimes, per-project pins | `~/.config/mise/config.toml`                      |
| [age](/management-tools/age)           | the two encrypted files in the repo               | `~/.config/chezmoi/key.txt`                       |

The [Cloudflare Worker](/management-tools/cloudflare) is not part of the machine. It serves the install command.

## Order on a fresh machine

1. chezmoi renders files and runs `run_once_before_decrypt-age-key`.
2. chezmoi runs `run_onchange_after_brew-bundle`, which installs Homebrew and then the Brewfile.
3. chezmoi runs `run_onchange_after_link-skills`, which clones `kiliantyler/skills` and links its skills. Before `gh auth login` the clone fails with a hint and apply carries on; signing in changes the script's trigger, so the next apply clones and links.
4. chezmoi runs `run_once_after_set-login-shell`, which needs the bash that step 2 installed.
5. mise installs each tool the first time its shim is called.
