Every file chezmoi writes into `~`, grouped by what it configures.

| Target                                              | Source in `dotfiles/`                                    | Page                                   |
| --------------------------------------------------- | -------------------------------------------------------- | -------------------------------------- |
| `~/.bash_profile`, `~/.bashrc`, `~/.zshenv`         | `dot_bash_profile`, `dot_bashrc`, `dot_zshenv`           | [Shell](/managed-dotfiles/shell)       |
| `~/.local/agent-bin/op`                            | `private_dot_local/agent-bin/executable_op`              | [Shell](/managed-dotfiles/shell#1password-for-agents) |
| `~/.agents/hooks/`, `~/.codex/hooks.json`, `~/.gemini/config/hooks.json` | `dot_agents/hooks/`, `dot_codex/hooks.json`, `dot_gemini/config/hooks.json` | [Agents](/managed-dotfiles/agents#t3-pr-watch-hooks) |
| `~/.local/bin/mcp-bridge`                          | `private_dot_local/bin/executable_mcp-bridge`            | [Agents](/managed-dotfiles/agents#mcp-servers-and-skills) |
| `~/.hushlogin`                                      | `empty_dot_hushlogin`                                    | [Shell](/managed-dotfiles/shell)       |
| `~/.default-python-packages`                        | `dot_default-python-packages`                            | [mise](/management-tools/mise)         |
| `~/.gitconfig`                                      | `private_dot_gitconfig.tmpl`                             | [Git and SSH](/managed-dotfiles/git-and-ssh) |
| `~/.config/git/allowed-signers`, `~/.config/git/ignore` | `private_dot_config/git/`                            | [Git and SSH](/managed-dotfiles/git-and-ssh) |
| `~/.ssh/config`                                     | `private_dot_ssh/private_config`                         | [Git and SSH](/managed-dotfiles/git-and-ssh) |
| `~/.config/gh/config.yml`                           | `private_dot_config/gh/config.yml`                       | [Git and SSH](/managed-dotfiles/git-and-ssh) |
| `~/.claude/settings.json`, `~/.claude/CLAUDE.md`, `~/.claude/skills/` | `dot_claude/`                          | [Agents](/managed-dotfiles/agents)     |
| `~/.gemini/GEMINI.md`                               | `dot_gemini/GEMINI.md.tmpl`                              | [Agents](/managed-dotfiles/agents)     |
| `~/.local/bin/hindsight-shared` | `private_dot_local/bin/executable_hindsight-shared` | [Shared memory](/managed-dotfiles/agents#hindsight) |
| Agent hook settings | `dot_codex/hooks.json.tmpl`, `dot_gemini/config/hooks.json.tmpl` and Claude's settings template | [Agent memory](/managed-dotfiles/agents#hindsight) |
| `~/.codex/AGENTS.md`                                | `dot_codex/AGENTS.md`                                    | [Agents](/managed-dotfiles/agents)     |
| `~/Library/Application Support/Code/User/settings.json` | `private_Library/Application Support/Code/User/`     | [Agents](/managed-dotfiles/agents)     |
| `~/Library/LaunchAgents/com.tailscale.start-at-login.plist` | `private_Library/LaunchAgents/` | [Homebrew](/management-tools/homebrew) |
| `~/.config/ghostty/`                                | `private_dot_config/ghostty/`                            | [Agents](/managed-dotfiles/agents)     |
| `~/.config/deployer/conf.d/*.env`                   | `private_dot_config/deployer/conf.d/` (private values encrypted) | [Agents](/managed-dotfiles/agents#deployer-registrations) |
| `~/.config/homebrew/Brewfile`                       | `private_dot_config/homebrew/Brewfile`                   | [Homebrew](/management-tools/homebrew) |
| `~/.config/mise/config.toml`                        | `private_dot_config/mise/config.toml`                    | [mise](/management-tools/mise)         |
| `~/.config/sops/age/private_keys.txt`               | `private_dot_config/sops/age/…​.age`                      | [age](/management-tools/age)           |

Not managed, by design: `~/.config/secrets.env`, `~/.config/op/agent.env`, `~/.config/deployer/webhook-secret`, Caddy's `~/.config/caddy/conf.d/*.caddy` (each app's installer writes its own), the rest of `~/.codex/` (Codex keeps its own state), shell history, and anything an app writes under `~/Library` other than VS Code settings.
